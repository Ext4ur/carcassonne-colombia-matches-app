# Knockout / tournament format backlog

Implemented in v1: `competition_format` `swiss` | `swiss_knockout`, manual start, top N power of 2, standard bracket seeding, 1v1 KO tables, best-of-1 or best-of-3 in one round.

**Not in v1 (planned):**

- Top X not a power of 2 (byes, play-in, top 4 direct to QF, etc.)
- Seeding: random, manual, re-seed each round
- Consolation / repechage bracket
- `round_robin` and reorderable `phases[]` in UI
- Multi-player KO tables
